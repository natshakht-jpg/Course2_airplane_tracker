# Трекер самолётов (Flight Tracker)

Консольное приложение для получения информации о самолётах в реальном времени над заданной страной с использованием OpenSky Network API и Nominatim API.

## Описание
Программа позволяет:
- Получить список самолётов над указанной страной.
- Сохранять полученные данные в JSON-файл.
- Выводить топ N самолётов по высоте полёта.
- Фильтровать самолёты по стране регистрации.

##  Установка и запуск
1. Клонируйте репозиторий:
   ```
   git clone <url-репозитория>
   cd Course2_airplane_tracker
   ```
   
2. Установите зависимости через Poetry:
    ```
    poetry install
    ```
   
3. Активируйте виртуальное окружение:
    ```
    poetry shell
    ```
   
4. Запустите программу:
    ```
    python main.py
    ```
   
## Тестирование

1. Запуск всех тестов:
    ```
    pytest tests/
    ```
   
2. Проверка покрытия:
    ```
    pytest --cov=src tests/ --cov-report=html
    ```
   
## Документация

### Класс Aeroplane (aeroplane.py)
- Хранит информацию о самолёте: icao24, callsign, origin_country, velocity, baro_altitude.
- Валидация данных при создании.
- Приватные атрибуты и геттеры (@property).
- Методы сравнения __lt__, __gt__, __eq__ (по скорости и высоте).
- __slots__ для экономии памяти.

### Классы для работы с API (aeroplanes_api.py)
- AbstractAeroplanesAPI — абстрактный класс с методом get_aeroplanes.
- AeroplanesAPI — конкретная реализация:
  - получает координаты страны через Nominatim API.
  - Запрашивает данные о самолётах через OpenSky API.
  - Возвращает JSON-ответ.

### Классы для работы с файлами (file_airinfo.py)
- BaseFileSaver — абстрактный класс с методами add_aeroplane, get_aeroplanes, delete_aeroplane.
- JSONSaver — сохраняет данные в JSON:
- Добавление без дубликатов (проверка по icao24).
- Чтение и фильтрация по критериям.
- Удаление записи по icao24.

### Модуль main.py
- Точка входа.
- Функция user_interaction() реализует консольный интерфейс:
- Ввод страны.
- Получение данных через AeroplanesAPI.
- Сохранение в JSON через JSONSaver.
- Вывод топа по высоте и фильтрация по стране.
